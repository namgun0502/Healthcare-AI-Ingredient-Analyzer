# Google AI Studio 대화형 어시스턴트 형태 레이아웃 개편 계획서

## 1. 개요
Google AI Studio Apps 형태의 2-Pane / 대화형 AI 어시스턴트 레이아웃으로 UI를 완전히 개편합니다.
좌측에는 실시간 AI 채팅 메시지 흐름 및 하단 메시지 입력창, 우측에는 입력된 약물/영양제 상태 및 추출된 표준 JSON 리포트를 시각화하는 사이드바 패널을 제공합니다.

## 2. 주요 UI 구성 요소
1. **좌측 메인 대화창 (Chat Workspace)**
   - 대화 기록 뷰 (유저 말풍선 & AI 어시스턴트 카드 응답 말풍선)
   - 입력 바 (텍스트 입력, 이미지 업로드 아이콘 버튼, 빠른 샘플 칩 선택 버튼)
2. **우측 대화 보조 사이드바 (Assistant & Data Panel)**
   - 복용 중인 기존 약물 목록 관리 칩
   - 최신 분석 결과의 규격화된 표준 JSON 데이터 뷰어 (Copy 기능 포함)
   - 의료 면책 및 주의사항 안내 가이드
