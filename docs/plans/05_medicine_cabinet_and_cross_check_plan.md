# 약물 & 영양제 내 보관함(Cabinet) 관리 및 AI 대조 분석 시스템 기획서

## 1. 개요
남건이 요청하신 핵심 사용자 경험(UX)인 **"약과 영양제를 사진이나 텍스트로 AI가 분석하여 개인 보관함(Cabinet)에 등록 및 저장하고, 챗봇과 대화할 때 보관함에서 선택한 복용약과 대조하여 상호작용 위험을 검증하는 시스템"** 기획 문서입니다.

## 2. 주요 프로세스 및 흐름 (Workflow)

```
[1단계: 등록 & 분석] 
  사용자가 약/영양제 사진 업로드 또는 텍스트 입력 
     ↓
  AI가 성분, 함량, 용법, 신뢰도 및 기본 분석 
     ↓
  [💾 내 보관함에 추가] 버튼 클릭으로 개인 보관함에 저장 (LocalStorage 기반 유지)

[2단계: 보관함(Cabinet) 선택 관리]
  우측 사이드바 "💊 내 약물/영양제 보관함"에서 내가 복용 중인 약 항목들을 체크박스로 선택/해제 

[3단계: 챗봇 실시간 대조 분석]
  새로운 약을 물어보거나 챗봇과 대화할 때 
     ↓
  보관함에서 [선택된 복용약 항목들]과 새로 입력된 약물 성분을 AI가 자동으로 비교 대조
     ↓
  상호작용 부작용, 성분 중복 오남용, 흡수 방해 위험을 정밀하게 대조 분석하여 리포트 출력
```

## 3. 세부 기능 사양
1. **사진 업로드 / 텍스트 등록 뷰**:
   - 약 포장지 사진 선택(파일 픽커) 시 AI 시뮬레이션 OCR 파싱 및 등록
2. **개인 약물 보관함 (Cabinet Drawer)**:
   - 등록된 약물 카드 리스트 (제품명, 주성분 태그, 등록일)
   - 선택(체크박스) 기능을 통해 "현재 복용 중인 약" 상태 토글
   - 개별 삭제 및 전체 삭제 기능
3. **대화 시 대조 분석 엔진 (Cross-Check Engine)**:
   - 챗봇에 "이 약 새로 먹어도 돼?" 입력 시 보관함의 선택된 약들과 자동으로 성분 대조
   - `SAFE`, `CAUTION`, `WARNING` 뱃지 및 대조 결과 리포트 자동 생성
