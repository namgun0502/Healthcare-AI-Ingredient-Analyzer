# 인앱 비밀번호 재설정 및 변경 기능 기획서

## 1. 개요
사용자(남건)가 비밀번호를 잊어버렸을 때 로그인 화면에서 **비밀번호 재설정 이메일 요청/재설정**을 수행하거나, 이미 로그인한 상태에서 **인앱 내 비밀번호 변경**을 안전하게 처리할 수 있도록 팝업 모달 및 UI 기능을 추가합니다.

## 2. 주요 기능 및 로직 정의
1. **로그인 화면 - [🔑 비밀번호를 잊으셨나요?] 모달**:
   - 로그인 폼 하단에 "비밀번호를 잊으셨나요?" 링크 제공.
   - 클릭 시 가입한 이메일을 입력하는 재설정 팝업 모달 오픈.
   - Supabase `supabaseClient.auth.resetPasswordForEmail(email)`을 호출하여 재설정 메일 발송 안내.
2. **로그인 후 인앱 화면 - [🔒 비밀번호 변경] 모달**:
   - 메인 앱 상단 내비게이션 바에 `[🔒 비밀번호 변경]` 버튼 추가.
   - 새 비밀번호 (6자 이상) 및 새 비밀번호 확인 입력.
   - 비밀번호 숨김/표시(👁️) 토글 기능 포함.
   - Supabase `supabaseClient.auth.updateUser({ password: newPassword })` 호출로 비밀번호 변경 완료.
3. **보안 규칙 준수 (규칙 8)**:
   - 최소 6자 이상 엄격한 검증 및 암호화 전송.
   - 변경 성공 시 보안을 위해 사용자에게 성공 알림 제공.
