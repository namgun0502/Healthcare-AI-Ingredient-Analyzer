# 챗봇 질문창 이미지 파일 드래그 앤 드롭(Drag & Drop) 첨부 기능 기획서

## 1. 개요
사용자(남건)가 약물 또는 영양제 포장지/알약 사진을 챗봇 입력창 주변으로 **드래그 앤 드롭(Drag & Drop)**하기만 해도, 버튼 클릭 없이 즉시 사진이 자동 첨부되고 분석 준비 상태가 되도록 웹 UI 및 자바스크립트 이벤트를 확장합니다.

## 2. 주요 기능 및 사용자 경험(UX) 정의
1. **드래그 앤 드롭 이벤트 감지**:
   - 질문 입력창 영역 (`.input-box-wrapper` 및 `.chat-pane`)에 `dragover`, `dragleave`, `drop` 이벤트를 등록합니다.
2. **시각적 반응 (Drag Over Visual Feedback)**:
   - 사용자가 이미지를 드래그하여 질문창 위로 가져오면, 입력 상자의 테두리와 배경이 에메랄드/블루 빛으로 밝아지며 "📷 사진을 여기에 놓아주세요!" 안내 뱃지나 효과가 나타납니다.
3. **이미지 파일 자동 인지 & 미리보기 처리**:
   - `drop` 이벤트 발생 시 파일 목록에서 이미지(`image/*`) 구분을 확인합니다.
   - 이미지가 첨부되면 `#image-preview-container` 영역을 자동으로 펼치고 첨부된 파일명을 표시합니다.
   - 질문 입력창에 기본 가이드문(`이 약/영양제 사진의 성분과 복용법을 분석하고, 내 보관함 약물들과의 상호작용 위험을 알려줘.`)을 자동으로 채워 넣어 편의성을 높입니다.
