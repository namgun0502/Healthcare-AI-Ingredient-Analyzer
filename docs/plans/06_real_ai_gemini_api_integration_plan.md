# Google Gemini API 연동 및 약품/영양제 실제 성분 지식베이스 구축 기획서

## 1. 개요
사용자(남건)가 입력한 임의의 약품명(예: 타이레놀, 우루사, 임팩타민, 게보린, 텐텐 등)이나 영양제 이름을 AI가 실제 의학 DB 및 Gemini API 모델과 연동하여 **실제 주성분, 함량, 효능, 부작용 및 상호작용**을 정확히 응답하도록 구축하는 기획서입니다.

## 2. 연동 구조 (Architecture)
1. **Gemini API 직접 연동 지원 (API Key 입력 폼 제공)**:
   - 사용자가 본인의 Google AI Studio Gemini API 키를 입력하면 실제 Google Gemini 1.5/2.0 AI 모델과 통신하여 실시간 성분 및 부작용 분석 결과를 응답받음.
2. **실제 한국 대표 약품/영양제 내장 데이터베이스 (Knowledge Base)**:
   - API 키가 없거나 Off-line 상태에서도 실제 시판되는 대표 약물/영양제의 진짜 성분 데이터를 정확히 반환하도록 약품 지식 베이스 구축:
     - **타이레놀**: 아세트아미노펜 500mg (진통제)
     - **우루사**: 우르소데옥시콜산(UDCA) 50mg, 비타민B1 10mg (간 기능 개선)
     - **게보린**: 아세트아미노펜 300mg, 이소프로필안티피린 150mg, 카페인무수물 50mg (소염진통제)
     - **임팩타민**: 벤포티아민(비타민B1) 50mg, 비타민B군 복합, 아연 (고함량 비타민)
     - **이부프로펜/이지엔6**: 이부프로펜 200mg (소염진통제)
     - **신지로이드**: 레보티록신나트륨 (갑상선호르몬제)
     - **아스피린**: 아스피린 100mg (항응고/항혈소판제)

## 3. 대조 분석 정밀화
- 입력된 실제 약물의 성분을 추출하여, 보관함의 선택된 약물들의 성분(예: NSAIDs 중복, 아세트아미노펜 중복 간독성, 비타민D 과다 등)을 정밀하게 교차 검증하도록 로직을 구현합니다.
