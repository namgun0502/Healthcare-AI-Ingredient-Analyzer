# 의약품 및 건강기능식품 AI 성분 분석 어시스턴트 서비스 설계 및 구동 계획서

## 1. 개요
남건을 위한 의약품 및 건강기능식품(영양제) 성분 분석과 오남용 방지 보조 AI 전문 헬스케어 어시스턴트 기능 구현 및 프론트엔드 시뮬레이터 구성 계획입니다.

## 2. 주요 기능
1. **제품 성분 및 용법 식별 (Identification & Dosage)**
   - 제품명, 의약품/건강기능식품 구분, 주성분 및 함량, 권장 복용법, 주의사항 추출
2. **상호작용 및 오남용 위험 분석 (Risk Analysis)**
   - 기존 복용 약물/영양제 목록과의 중복 섭취 및 상호작용 부작용 검증
   - 일일 권장량 초과 시 강력한 경고(WARNING) 안내
3. **구조화된 JSON 응답 생성**
   - 규격화된 JSON 데이터 포맷 출력 지원
4. **대화형 UI / 시뮬레이터 (웹 앱)**
   - 웹 화면에서 이미지/텍스트 입력, 기존 복용약 목록 입력 및 분석 결과를 한눈에 확인하고 테스트할 수 있는 데모 인터페이스 제공

## 3. 세부 JSON 출력 규격
```json
{
  "identification": {
    "product_name": "제품명 또는 식별된 이름",
    "type": "의약품 | 건강기능식품 | 식별불가",
    "main_ingredients": [
      {"name": "성분명", "amount": "함량"}
    ],
    "confidence_score": "HIGH | MEDIUM | LOW"
  },
  "dosage_guide": {
    "recommended_daily": "권장 복용량 및 방법",
    "precautions": ["주의사항 1", "주의사항 2"]
  },
  "risk_analysis": {
    "has_risk": true,
    "risk_level": "SAFE | CAUTION | WARNING",
    "warnings": [
      "비타민 D 중복 섭취로 인한 일일 권장량 초과 위험 (총 5,000 IU)"
    ]
  },
  "user_summary": "사용자가 읽기 쉬운 2~3줄 요약 문장"
}
```

## 4. 안전 및 주의사항 준수
- 참고용 정보임을 명시하고 의사/약사 상담을 안내합니다.
- 식별 불분명 시 재촬영 및 명확한 항목 지정을 안내합니다.
