# 인앱 닉네임 미설정 계정 자동 팝업 및 설정/수정 기능 기획서

## 1. 개요
기존 계정 중 닉네임이 미설정되어 있거나 기본값('사용자', null, 빈문자열 등)으로 되어 있는 사용자가 로그인하여 앱 진입 시, **인앱(Main App) 내에서 닉네임 설정 모달이 자동으로 안내**되어 입력받도록 개선합니다. 
또한 상단 내비게이션 바의 **[✏️ 닉네임 수정]** 버튼을 통해 사용자가 원할 때 언제든 닉네임을 수정할 수 있습니다.

## 2. 주요 기능 및 처리 로직
1. **미설정 계정 자동 감지 & 팝업 열기**:
   - `showMainApp(user)` 시 Supabase `profiles` 및 `user_metadata`에서 닉네임을 조회합니다.
   - 닉네임이 없거나, `사용자`, `null`, 빈 문자열인 경우 **닉네임 설정 모달 (`#nickname-modal`)을 자동으로 표시**합니다.
2. **수동 닉네임 수정 기능**:
   - 상단 내비게이션의 `[✏️ 닉네임 수정]` 버튼 클릭 시 모달 팝업 오픈 및 기존 닉네임 자동 세팅.
3. **Supabase 프로필 DB 및 Auth Metadata 업데이트**:
   - 닉네임 저장 시 Supabase `profiles` 테이블에 `upsert` 수행.
   - Supabase `auth.updateUser({ data: { nickname: newNickname } })` 호출로 메타데이터도 함께 동기화.
   - 화면 상단 `👤 닉네임 (이메일)` 표시 및 약물 보관함 안내문 실시간 업데이트.
